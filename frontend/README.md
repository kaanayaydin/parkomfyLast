# Parkomfy

Parkomfy, otopark rezervasyon ve yönetim uygulamasıdır. Kullanıcılar otopark alanlarını görüntüleyebilir, rezervasyon yapabilir ve ödemelerini kolayca gerçekleştirebilir.

## Özellikler
- Kullanıcı kaydı ve girişi
- Otopark alanlarını listeleme ve detay görüntüleme
- Rezervasyon oluşturma ve yönetme
- Ödeme özeti ve işlemleri
- Profil ve ayarlar yönetimi
- Yönetici paneli

## Kurulum
1. Depoyu klonlayın:
   ```sh
   git clone <repo-link>
   ```
2. Proje dizinine girin:
   ```sh
   cd Parkomfy
   ```
3. Bağımlılıkları yükleyin:
   ```sh
   npm install
   ```
4. Expo ile başlatın:
   ```sh
   npx expo start
   ```

## Kullanılan Teknolojiler
- React Native
- Expo
- JavaScript
