================================================================================
KAAN_JOURNAL  -  Kaan'in AI Agent Calisma Gunlugu (Parkomfy Projesi)
================================================================================
Bu dosya, Kaan'in agent'i (Cursor AI) tarafindan bu projede yapilan tum
calismalarin detayli ve kronolojik kaydidir. Her yeni guncellemede en alta
yeni bir kayit eklenir. (Eren'in agent'i da kendi gunlugunu ayri tutacak.)

Bicim: Her kayit -> [TARIH] Baslik / Ne yapildi / Neden / Etkilenen dosyalar.
================================================================================


--------------------------------------------------------------------------------
PROJE GENEL MIMARISI (referans)
--------------------------------------------------------------------------------
Parkomfy 3 ana bilesenden olusan bir otopark/plaka tanima sistemidir:

  1) grpc_server/  : Python gRPC + Bilgisayarli Goru (CV) sunucusu (:50051)
                     - YOLO (arac/slot tespiti), OCR (plaka okuma)
                     - Kamera simulasyonu / RTSP kaynagi
  2) src/main/java : Java Spring Boot backend (:8080)
                     - REST API (frontend icin), gRPC istemcisi (Python'a)
                     - Plaka takip, oturum/lifecycle, slot doluluk yonetimi
  3) frontend/     : Expo / React Native mobil uygulama (:8081)
                     - Giris/kayit, otopark durumu, rezervasyon, profil

Iletisim: Frontend --REST--> Java --gRPC--> Python CV ; Java --HTTP--> kamera sim.
